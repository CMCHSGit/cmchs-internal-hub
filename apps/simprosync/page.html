How it works: assets are matched on Serial Number within each Site ID. Existing assets are updated, new serials are created. Blank cells never clear Simpro, values not in a Simpro list are rejected, Excel errors such as #REF! are skipped, and the sync never deletes anything. If the sheet has a Simpro Job column, each job's assets are attached to it after the import and the job is set to stage Complete / status Job : Completed — only if every asset attached.
